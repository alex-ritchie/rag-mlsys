# Deviations from the design document

Running log. Each entry: what the spec says, what reality required, why, and what the intent-preserving
replacement is.

| # | Date | Spec | Deviation | Why |
|---|---|---|---|---|
| 1 | 2026-08-21 | §2 "NVIDIA driver ≥ 550 (CUDA 12.x runtime)" | Driver is 575.57 (CUDA 12.9). Default PyPI `torch` wheels now target CUDA 13, which this driver rejects (`RuntimeError: The NVIDIA driver on your system is too old`). `pyproject.toml` pins the **cu128** PyTorch wheel index. vLLM is installed from the `+cu129` wheel on the GitHub release (the PyPI wheel is CUDA 13) into a separate venv `data/vllm-venv` (`make setup-vllm`) because it pins `torch==2.13.0` exactly; the main workspace keeps its own torch. | Prefer reality; intent (CUDA 12.x runtime on Ampere) preserved. |
| 2 | 2026-08-21 | §5.1 "walk the Quarto `.qmd` sources" — chapter order implied from the book config | At the pinned SHA the book is a Quarto **website** project, not a `book:` project: chapter order lives in `project.render` of `book/quarto/config/_quarto-html-vol{1,2}.yml`. `chapter_files_from_quarto_config` supports both shapes. Front-matter, part dividers, references, and the shared SocratiQ page are skipped; appendices are numbered from 100 and the glossary is 200 so `chapter_num` stays a single SMALLINT. | Reality of the repo layout. |
| 3 | 2026-08-21 | §5.1 strip list: callouts, shortcodes, div attributes | The sources also contain hidden `{python}` computation cells (`#| echo: false`), inline `` `{python} expr` `` value substitutions, `\index{}` macros, TikZ diagrams, footnote markers, and citation brackets. Cells/TikZ/PDF-only blocks/learning-objective and quiz scaffolding are dropped; inline values are replaced by `[value]`; footnote *definitions* are kept as paragraphs (they are glossary-like content). | Keeps chunks free of build-time noise while preserving every reader-visible fact. |
| 4 | 2026-08-21 | §4 M6 `docker compose up`, §2 Docker | The build host has Docker installed but the user is not in the `docker` group and has no passwordless sudo; no `psql` either. Unit + integration tests therefore run Postgres+pgvector via the `pgserver` pip package (unprivileged, no daemon), exposed as `make db-up`. The compose path is written and the Dockerfiles are complete, but **compose has not yet been executed end-to-end on this host** — see the runbook status table. | Could not be exercised without group membership; nothing in the design depends on it for development. |
| 5 | 2026-08-21 | §5.8 `kubectl apply -f k8s/` brings up everything | Kept, with one exception: `k8s/_index-job.yaml` (a one-shot GPU Job that builds the index) is deliberately excluded from the directory apply (`make k8s-apply` applies the numbered files only), because a directory apply would re-create the Job on every apply and it competes with vLLM for the GPU. Prometheus alert rules and Grafana dashboard JSON are kept as plain files and embedded into ConfigMaps by `scripts/sync_k8s_configmaps.py` (no Kustomize generator). | Plain-manifest constraint kept; avoids a GPU fight on re-apply. |
| 6 | 2026-08-21 | §5.5 "p50 gateway overhead < 150 ms measured" | Measured in-process through the ASGI app with fake embedder/reranker/LLM and a real Postgres (`gateway/tests/test_api.py::test_gateway_overhead_under_150ms`): p50 ≈ 15–25 ms end-to-end including retrieval SQL. A network-level measurement against the deployed gateway (the `rag_gateway_overhead_seconds` histogram) is part of M8. | Same intent, two measurement points. |
| 7 | 2026-08-21 | §5.4 Qwen3 thinking disabled "in the system prompt" | Disabled through vLLM's `chat_template_kwargs: {enable_thinking: false}` (the supported mechanism for Qwen3.x chat templates) rather than prompt text; `DISABLE_THINKING` env toggles it so reasoning on/off is a clean M8 lever. | Mechanism, not intent, changed. |
| 8 | 2026-08-21 | §5.11 Node ≥ 20, `pnpm` | System Node was v12; installed Node 22.12 user-locally under `~/.local/opt/node` and pnpm 9 via npm (corepack's bundled signing key is stale on that Node build). The Makefile prepends that path. | Tooling only. |
| 9 | 2026-08-21 | §5.4 baseline `--gpu-memory-utilization 0.90`; VRAM table "CUDA context + activations ~1–1.5 GB" | At 0.90 vLLM 0.27.1 leaves only 1.52 GiB for KV on the 3090 Ti (overhead ≈ 3.6 GiB) and refuses to serve 32K. 0.95 passed the 10-min c8 soak, but rung 1 of the ladder (reranker on CPU) was measured at 22.6 s/query and rejected. Final: **util 0.90 + `--max-model-len 16384`** (rung 4) with the **reranker on the GPU** at `max_length` 512 and the embedder on CPU. The ladder's order was inverted by measurement. | See `docs/benchmarks/m3-baseline.md` attempts 1–5. |
