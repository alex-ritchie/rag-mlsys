# Benchmark report: serving a 27B RAG companion on one 3090 Ti

*Blog-style report (design doc §5.12). Status: **methodology and harness complete; numbers pending
M3/M8 runs on the workstation** — every table below is generated by `make bench-report` /
`make eval` and the cells are filled from `bench/results/*.json` and `eval/results/*/report.json`.
No number in this document is typed by hand.*

## 1. Methodology

- **Hardware:** RTX 3090 Ti 24 GB (Ampere, sm_86), Ryzen 9 7900X3D, 96 GB RAM, driver 575 (CUDA 12.9).
- **Workload:** 16 textbook questions (`bench/configs/prompts.txt`), cycled round-robin, closed-loop
  load at concurrency ∈ {1, 4, 8, 16, 32}, 48 requests per level after 2 warm-ups. Two targets:
  end-to-end through the gateway (`target: gateway`) and engine-isolated (`target: openai` against vLLM
  directly, same prompts, thinking off).
- **Metrics:** TTFT p50/p99, total latency p50/p99, output tokens/s, requests/s, per-stage p50 from
  the gateway's `latency_breakdown`. Every result JSON embeds the serving config, git SHA, GPU, and the
  server's self-reported model/version.
- **Quality:** the hand-verified golden set (≈140 questions: 60 % single-chunk, 30 % multi-chunk,
  10–15 unanswerable), retrieval recall@{5,10,30}/MRR for dense → hybrid → hybrid+rerank, and three
  LLM-judge scores (faithfulness, relevance, groundedness/abstention) validated against 30 owner labels.
